# Track Your Budget – Frontend

React 19 + TypeScript + Vite single-page app. See the [project README](../README.md) for the full setup, API and authentication flow.

## Scripts

| Command | Purpose |
|---|---|
| `npm run dev` | Dev server on `http://localhost:5173`, proxying `/api` to `http://127.0.0.1:8000` |
| `npm run build` | Type-check and production build into `dist/` |
| `npm run lint` | ESLint |
| `npm run format` | Prettier over `src/` (`format:check` only reports) |

## Configuration

Copy `.env.example` to `.env.local` and set the full authorization URL of each provider you want to offer. A login button is hidden when its variable is empty.

| Variable | Meaning |
|---|---|
| `VITE_GOOGLE_LINK` | Google OAuth 2.0 authorization URL, `response_type=code` |
| `VITE_GITHUB_LINK` | GitHub authorize URL |
| `VITE_MICROSOFT_LINK` | Microsoft identity platform authorize URL |

In the Docker image the same three values are read from the container environment at start-up and written to `env-config.js`, so one image serves every environment.

## Layout

- `src/App.tsx` routes; every page except `/login` sits behind `RequireAuth`.
- `src/hooks/use-auth-session.ts` owns the token lifecycle.
- `src/lib/api/` holds every request; pages never build URLs themselves.
- `src/components/ui/` is generated by shadcn and excluded from Prettier.
